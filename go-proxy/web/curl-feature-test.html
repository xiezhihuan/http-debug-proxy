复制为curl功能测试

✅ 功能说明：新增"复制为curl"按钮，可以将HTTP请求转换为标准的curl命令格式，方便在命令行中执行

🎯 功能特点：

🔧

智能转换

  • 自动识别HTTP方法
  • 智能处理请求头
  • 根据Content-Type选择参数
  • 跳过不必要的头部信息
📋

一键复制

  • 生成标准curl命令
  • 自动复制到剪贴板
  • 支持多行格式化
  • 便于命令行执行
🎨

格式优化

  • JSON数据使用单引号
  • 表单数据使用双引号
  • 二进制数据使用--data-binary
  • 自动换行提高可读性

📚 使用场景：

  • 命令行调试：在终端中直接执行curl命令测试API
  • 脚本自动化：将curl命令集成到shell脚本中
  • 文档记录：为API文档提供可执行的示例命令
  • 团队协作：分享curl命令给其他开发者
  • CI/CD集成：在自动化测试中使用curl命令
  • 故障排查：快速重现和调试HTTP请求问题

🔍 技术实现细节：

请求头处理

  • 自动跳过 Host 头部
  • 跳过 Content-Length 头部
  • 跳过 Connection 头部
  • 保留所有业务相关头部

请求体处理

  • JSON: 使用 -d 参数
  • 表单: 使用 -d 参数
  • 二进制: 使用 --data-binary
  • 空请求体: 不添加参数

URL处理

  • 自动添加双引号包围
  • 支持特殊字符转义
  • 保持原始URL格式
  • 处理查询参数
