🔄 重放次数功能测试

✅ 功能说明：重放请求现在支持设置重放次数（1-1000次），可选择顺序执行或并发执行，并提供进度指示和结果统计

🎯 新增功能特点：

🔢

重放次数设置

  • 支持1-1000次重放
  • 数字输入框验证
  • 默认值为1次
  • 灵活的范围设置
⚡

执行方式选择

  • 顺序执行：一次完成后再执行下一次
  • 并发执行：同时执行多个请求
  • 智能进度更新
  • 性能优化选择
📊

进度指示器

  • 实时进度条显示
  • 当前重放次数/总次数
  • 取消重放功能
  • 视觉反馈清晰
📈

结果统计

  • 成功/失败次数统计
  • 成功率百分比
  • 详细结果列表
  • 日志ID记录

📚 使用场景：

  • 压力测试：测试API在高并发下的性能表现
  • 稳定性测试：验证API在多次请求下的稳定性
  • 性能基准：获取多次请求的平均响应时间和成功率
  • 故障重现：多次重放以重现偶发性问题
  • 负载测试：模拟真实的用户请求模式
  • 回归测试：验证修复后的功能是否稳定

🔍 技术实现细节：

顺序执行

  • 使用 for 循环顺序执行
  • 每次执行后更新进度
  • 支持取消操作
  • 添加延迟避免过快请求

并发执行

  • 使用 Future.wait 并发执行
  • 实时更新进度状态
  • 支持取消操作
  • 性能更高但资源消耗大

进度管理

  • 实时进度条更新
  • 当前次数/总次数显示
  • 取消按钮状态管理
  • 结果收集和统计

结果展示

  • 成功/失败次数统计
  • 成功率百分比计算
  • 详细结果列表展示
  • 日志ID记录和显示
