📝 JSON格式化功能测试

重放对话框中的JSON请求体格式化与压缩功能

✨ 新增功能

在重放请求对话框的请求体区域添加了JSON格式化和压缩功能！
支持4个空格缩进格式化，智能检测JSON有效性，无效JSON时不执行操作。

🎯 智能检测

自动检测JSON内容：

  • 基于Content-Type头判断
  • 根据请求体内容结构判断（{} 或 []）
  • 仅在JSON内容时显示格式化按钮
  • 初始化时自动格式化历史JSON请求

🔧 操作按钮

两个便捷按钮：

⚡ 格式化JSON
📦 压缩JSON

位置：请求体区域的头部，Content-Type信息右侧

📐 格式化规则

4个空格缩进：

  • 使用4个空格（非制表符）
  • 嵌套结构清晰展示
  • 保持JSON语法正确性
  • 易于阅读和编辑

🛡️ 错误处理

安全的错误处理：

  • JSON解析失败时显示错误提示
  • 不会破坏原始数据
  • 空内容时给出友好提示
  • 操作成功时显示确认消息

🔴 格式化前

{"user":{"id":123,"name":"张三","email":"zhangsan@example.com","profile":{"age":25,"city":"北京","skills":["JavaScript","Python","Java"]},"settings":{"theme":"dark","notifications":true}}}

🟢 格式化后（4个空格）

{ "user": { "id": 123, "name": "张三", "email": "zhangsan@example.com", "profile": { "age": 25, "city": "北京", "skills": [ "JavaScript", "Python", "Java" ] }, "settings": { "theme": "dark", "notifications": true } } }

🧪 测试场景

1. 有效JSON测试

测试数据： {"name":"test","data":{"items":[1,2,3],"active":true}} 预期结果： - 格式化：使用4个空格缩进，结构清晰 - 压缩：去除所有空格和换行，变成一行 - 提示：显示"JSON格式化成功"或"JSON压缩成功"

2. 无效JSON测试

测试数据： {name:"test",data:invalid} 预期结果： - 格式化：显示"JSON格式无效，无法格式化" - 压缩：显示"JSON格式无效，无法压缩" - 内容：保持原样，不被修改

3. 空内容测试

测试数据： (空内容) 预期结果： - 格式化：显示"请求体为空，无法格式化" - 压缩：显示"请求体为空，无法压缩"

4. 非JSON内容测试

Content-Type: text/plain 请求体：普通文本内容 预期结果： - 不显示格式化和压缩按钮 - 因为Content-Type不包含"json"

🔍 测试步骤

  1. 准备环境：
    • 确保Flutter Web应用运行在 http://localhost:8092
    • 确保有包含JSON请求体的HTTP历史记录
  2. 测试自动格式化：
    • 选择一个包含JSON请求体的历史请求
    • 点击重放按钮
    • 观察请求体是否自动格式化（4个空格）
  3. 测试手动格式化：
    • 在请求体中输入压缩的JSON
    • 点击"格式化JSON"按钮
    • 观察是否正确格式化并显示成功提示
  4. 测试压缩功能：
    • 确保请求体中有格式化的JSON
    • 点击"压缩JSON"按钮
    • 观察是否压缩为一行并显示成功提示
  5. 测试错误处理：
    • 输入无效JSON内容
    • 点击格式化或压缩按钮
    • 观察是否显示错误提示且内容不变
  6. 测试按钮显示逻辑：
    • 修改Content-Type为非JSON类型
    • 观察格式化按钮是否隐藏
