📋 历史请求选择功能演示

从HTTP请求日志列表中选择请求并添加到序列编排

✨ 功能特性

🎯 真实数据源

直接从左侧"HTTP请求日志"列表中获取真实的HTTP请求数据，无需手动输入。

🔍 搜索过滤

支持按URL、方法类型进行搜索和过滤，快速找到需要的请求。

📝 完整信息

自动复制请求的完整信息，包括URL、方法、头部、请求体等所有详细数据。

✏️ 描述编辑

允许用户为选中的请求添加或修改描述信息，便于序列管理。

⏰ 时间排序

按时间倒序显示，最新的请求在前面，更符合用户使用习惯。

👁️ 详情预览

支持查看请求的详细信息，包括请求头、请求体的完整内容。

💡 使用流程

步骤1： 在请求序列编排中点击"添加请求"按钮
步骤2： 从弹出的历史请求列表中浏览和搜索
步骤3： 点击"查看详情"预览请求的完整信息
步骤4： 点击"添加到序列"选择请求
步骤5： 编辑请求描述并确认添加
