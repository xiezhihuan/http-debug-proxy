主要改进点

  • 布局结构：从两列布局改为垂直布局，确保每个区域都有足够的空间
  • 高度设置：为请求头和请求体区域设置固定高度（200px），避免内容被截断
  • 滚动支持：使用 SingleChildScrollView 支持内容滚动，适应不同内容长度
  • 空间分配：合理分配各个区域的空间，确保所有可编辑内容都能完整显示
  • 用户体验：优化后的布局让用户可以完整查看和编辑所有内容，提升操作效率

  • Dialog 容器：1000x800
  • SingleChildScrollView 支持滚动
