🚀 请求编排功能演示

支持多个HTTP请求的序列化重放和循环执行

✨ 功能特性

🎯 请求序列编排

支持添加多个不同的HTTP请求，按顺序执行。每个请求可以设置不同的URL、方法和描述。

🔄 循环执行

整个请求序列可以重复执行指定的次数，支持1-1000次的循环范围。

📊 实时进度

显示当前执行轮次和请求序号，提供进度条和详细的状态信息。

⏹️ 执行控制

支持取消正在执行的序列，提供完整的执行控制能力。

📈 结果统计

执行完成后显示详细的统计信息，包括成功率、失败次数等。

🔧 灵活配置

支持编辑和删除序列中的请求，动态调整执行计划。

💡 使用场景

API测试流程： 测试完整的业务流程，如登录 → 查询 → 操作 → 登出
性能测试： 模拟真实的用户操作序列，测试系统性能
集成测试： 验证多个API接口的协作和依赖关系
回归测试： 重复执行特定的测试场景，确保系统稳定性
