🎯 功能演示：

🔗 URL 复制

快速复制请求的 URL 地址

https://httpbin.org/post?param1=value1¶m2=value2

适用于：快速分享链接、在新标签页打开等

📄 完整信息复制

复制请求的完整详细信息

HTTP请求详情 方法: POST URL: https://httpbin.org/post 状态码: 200 耗时: 150ms ...

适用于：调试分析、文档记录等

📊 功能对比：

URL 复制功能
  • 只复制请求的 URL 地址
  • 操作快速，响应迅速
  • 适用于链接分享和导航
  • 数据量小，剪贴板友好
  • 右键菜单中的"复制URL"按钮
完整信息复制功能
  • 复制请求的所有详细信息
  • 包含方法、状态码、请求头、响应体等
  • 适用于调试和文档记录
  • 数据量大，信息完整
  • 详情页面的"复制完整详情"按钮

🔧 使用方法：

🖱️ 右键菜单

在日志列表中右键点击任意请求：

  • 🔄 重放请求
  • 📋 复制URL ← 只复制URL
  • 🗑️ 删除日志

📱 详情页面

在请求详情页面：

  • 🔗 复制URL ← 只复制URL
  • 📋 复制完整详情 ← 复制所有信息
